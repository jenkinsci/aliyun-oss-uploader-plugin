# Aliyun OSS Uploader 2.1.0 发布说明

[English](2.1.0.md) | 简体中文

发布日期：2026 年 11 月 16 日。

2.1.0 将最低 Jenkins 版本从 2.555.3 降至 **2.479.3**，最低 Java 版本从 21 降至 **17**，让更多旧环境能够使用 2.0.0 中的对象 ACL、缺失路径处理及 Pipeline 修复。

## 环境要求

- Jenkins **2.479.3 或更新版本**。
- 在该基线上支持 **Java 17 或 Java 21**；较新的 Jenkins 版本可能要求更高版本的 Java。控制器与代理的 Java 均需满足所用 Jenkins 的要求。
- 源码构建需要 Maven **3.9.6 或更新版本**及 JDK 17/21；Maven Wrapper 使用 3.9.9。

已发布的 2.0.0 安装包仍要求 Jenkins 2.555.3 和 Java 21；降低环境要求的改动从 2.1.0 生效。

## 兼容性调整

- 使用匹配 Jenkins 2.479 基线的 BOM，调整 Pipeline 测试依赖和 Gson API 版本。
- 保留仍兼容 Jenkins 2.479.3 的 Structs 与 Commons Lang API 版本。
- 明确依赖 Bouncy Castle API 插件，为阿里云 SDK 提供加密库，并相应更新严格 HPI 打包清单。
- 编译目标降至 Java 17，CI 使用 Java 17 和 Java 21。

上传业务代码及阿里云 OSS SDK 3.18.5 保持不变。已有任务 XML、`aliyunOSSUpload` 参数、对象 ACL 和缺失路径选项继续兼容，无需改写已有 Pipeline。

## 升级与验证

通过 Jenkins 插件管理器安装 2.1.0 及其依赖；手工上传 HPI 时也需安装符合版本要求的依赖插件。此前使用 1.x 且 Jenkins 低于 2.479.3 的环境仍需先升级 Jenkins 与 Java。

Jenkins 2.479.3 下的 Java 17、Java 21 环境各通过 21 项自动测试，静态检查与 HPI 打包校验通过。测试覆盖旧配置还原、Pipeline 执行、文件与目录上传、ACL 请求头以及缺失路径行为；本次未重复运行真实 OSS 烟测。
